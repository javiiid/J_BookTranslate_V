FAQ

Do my files leave my device? +

Only the text chunks are sent to your configured Provider. The key is read from config.yaml on this machine and never exposed to the browser. Local convert needs no key at all.

What about RTL (Persian/Arabic)? +

DOCX adds w:bidi per paragraph when the target is RTL. PDFs use HTML bidi and keep selectable text.

Can I resume after a crash? +

Yes — every chunk is persisted. Re-run or hit Resume; the pipeline continues from the last healthy chunk (EPUB).

Which models work? +

Any OpenAI-compatible endpoint. Configure base_url to end with /v1 and set your key in Settings.
