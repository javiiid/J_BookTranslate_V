# مرکز راهنما — راهنمای افزودن محتوا

این صفحه برای کسی است که می‌خواهد مقاله، پرسش، مترادف جست‌وجو یا ویدیو
به `/help` اضافه کند. بدون نیاز به دست‌زدن به JSX صفحه‌ها.

## کجاها چه چیزی زندگی می‌کند

| چه | کجا |
| --- | --- |
| موتور جست‌وجو و مدل محتوا | `ui/src/lib/help.ts` (خالص، بدون import) |
| متن فارسی | `ui/src/help/content.fa.ts` |
| متن انگلیسی | `ui/src/help/content.en.ts` |
| انتخاب زبان و برچسب دسته‌ها | `ui/src/help/corpus.ts` |
| متن‌های رابط (دکمه‌ها، عنوان‌ها) | `ui/src/i18n/fa.ts` + `en.ts` (کلیدهای `help.*`) |
| تست‌ها | `ui/tests/help.test.ts` |

## افزودن مقاله

۱. در **هر دو** فایل محتوا یک شیء با همان `id`، `slug` و `category` اضافه کنید.
   - `slug` لاتین، پایدار و یکتا باشد: نشانی `/help/articles/:slug` است و
     بعد از انتشار نباید عوض شود.
   - `category` یکی از هفت دستهٔ `HELP_CATEGORIES` در `lib/help.ts`.
   - `sections` حداقل یک بخش با `id` یکتا داشته باشد؛ `id` بخش‌ها در هر دو
     زبان یکی باشند تا anchor `#sec-…` با تعویض زبان نشکند.
   - `relatedSlugs` فقط slugهای موجود؛ `reviewedAt` تاریخ واقعی بازبینی
     (`YYYY-MM-DD`)، نه امروزِ خودکار.
۲. `npm run typecheck` و `node --test tests/help.test.ts` را اجرا کنید؛
   تست یکپارچگی slug تکراری، دستهٔ نامعتبر و لینک خراب را می‌گیرد.

قانون‌های محتوا: نام دکمه‌ها و مسیرها عین رابط باشند؛ چیزی که برنامه
ندارد (OCR، لغو تبدیل، پرداخت فعال) ادعا نشود؛ جزئیات داخلی (نام تابع،
جدول دیتابیس) در متن کاربر عادی نیاید؛ راه‌حل اول رفع اشکال هرگز حذف
فایل وضعیت یا شروع دوبارهٔ پرهزینه نباشد.

## افزودن FAQ

در هر دو فایل، شیء `{ id, question, answer, category, articleSlug? }`.
`articleSlug` اختیاری است و باید به مقالهٔ موجود اشاره کند. لینک نتیجهٔ
جست‌وجو، آیتم درست را با `?faq=<id>` باز و به محلش اسکرول می‌کند.

## افزودن مترادف جست‌وجو

در `HELP_SYNONYMS` در `lib/help.ts` یک گروه اضافه کنید، مثلاً
`['refund', 'بازپرداخت']`. گروه‌ها پیش از نرمال‌سازی نوشته و پس از آن
مقایسه می‌شوند؛ منطق AND است: هر واژهٔ پرس‌وجو باید جایی پیدا شود.

## افزودن ویدیو

`helpVideosFa` / `helpVideosEn` فعلاً خالی‌اند چون ویدیوی واقعی وجود
ندارد — و همین درست است: بخش «آموزش ویدیویی» تا آن زمان حالت خالی
صادقانه نشان می‌دهد و جست‌وجو نتیجهٔ ویدیویی جعلی نمی‌سازد. برای افزودن:

```ts
{ id: 'calibration-tour', title: '…', description: '…', category: 'getting-started',
  url: 'https://…', provider: 'youtube', duration: '…(واقعی)', transcript: '…(اگر هست)' }
```

- `provider` فقط `youtube` یا `link`؛ نشانی دلخواه هرگز به iframe تبدیل
  نمی‌شود.
- `duration` و `thumbnail` فقط از دادهٔ واقعی؛ `transcript` فقط اگر فایل
  واقعی هست.
- نشانی باید `https` باشد (تست یکپارچگی می‌گیرد).
